# Security Policy

## Reporting a Vulnerability

If you have discovered a security vulnerability in this project, we appreciate your help in disclosing it to us responsibly. Please do not report security issues in public GitHub issues.

Instead, please use Github feature: **Report a vulnerability**

We will aim to acknowledge your report within [e.g., 72 hours] and provide an update on the investigation.

## Supported Versions

We are committed to maintaining the security of our software. Security patches and updates are only provided for the **latest application series**.

| Version | Supported |
| --- | --- |
| **x.y.z** | **Yes** (Active) |
| < x.y.z | No |

If you are using an older version, please upgrade to the latest release in the 2.7.x series to receive the latest security fixes.

## Disclosure Policy

* We request that you keep the details of any discovered vulnerability confidential until we have had a reasonable amount of time
(e.g., [e.g., 90 days]) to investigate and release a fix.
* We will provide credit to researchers who report vulnerabilities that are verified and fixed.
